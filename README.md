# Розпізнавання показників водяного лічильника (YOLOv8 + Faster R-CNN)

## Опис проєкту

Веб-додаток на базі Streamlit для автоматичного зчитування показників з фотографій водяних лічильників. Проєкт використовує сучасний pipeline комп'ютерного зору: семантичну сегментацію екрана за допомогою YOLOv8, математичне вирівнювання перспективи (OpenCV) та детекцію окремих цифр за допомогою архітектури Faster R-CNN на базі PyTorch.

## Архітектура

Процес розпізнавання поділено на два незалежні етапи:

1. **Локалізація та вирівнювання (YOLOv8 + Perspective Transform):** Модель YOLOv8 генерує маску циферблата лічильника. Далі алгоритм за допомогою `cv2.minAreaRect` знаходить 4 кути цієї маски і застосовує вирівнювання перспективи (`cv2.warpPerspective`). Це дозволяє програмно перетворити фотографію, зроблену під будь-яким кутом, на ідеально рівний прямокутник екрана.
2. **Детекція та читання цифр (Faster R-CNN):** Вирівняне зображення передається у модель Faster R-CNN (з бекбоном ResNet50 FPN). Нейромережа одночасно знаходить координати (bounding boxes) кожної цифри та визначає її клас (0-9). Результати сортуються зліва направо за координатою осі X.

## Структура репозиторію

* `app.py` — головний файл веб-додатка, що містить логіку інтерфейсу Streamlit, математичних трансформацій та інференсу обох нейромереж.
* `models/` — директорія для збережених ваг моделей (`best.pt` для масок YOLO, `rcnn_meter_best.pth` для Faster R-CNN).
* `notebooks/` — Jupyter ноутбуки з повним циклом підготовки проєкту: завантаження COCO-анотацій з Roboflow, написання кастомних `Dataset` класів для PyTorch та тренування R-CNN з логуванням функцій втрат.
* `requirements.txt` — список Python-залежностей, необхідних для запуску проєкту.

## Локальний запуск

1. Створіть та активуйте віртуальне середовище:

```bash
python -m venv venv
.\venv\Scripts\Activate.ps1

```

2. Встановіть необхідні залежності:

```bash
pip install -r requirements.txt

```

3. Запустіть веб-додаток через Streamlit:

```bash
streamlit run app.py

```

Після виконання команди додаток буде доступний у браузері за адресою `http://localhost:8501`.

## Технічні особливості реалізації

* **Математичне вирівнювання перспективи:** Замість тренування додаткових нейромереж для вирівнювання (напр. YOLO-Pose), імплементовано класичний алгоритм комп'ютерного зору. Пропорції екрана динамічно розраховуються через Евклідову відстань між знайденими кутами маски.
* **Non-Maximum Suppression (NMS):** Для вирішення проблеми дублювання рамок (overlapping boxes) реалізовано алгоритм придушення немаксимумів (`torchvision.ops.nms`). Він відфільтровує надлишкові передбачення (з `iou_threshold=0.1`), залишаючи лише одну найбільш впевнену рамку для кожної фізичної цифри.
* **Обробка специфіки COCO/Roboflow:** Враховано архітектурну вимогу Faster R-CNN, де клас `0` жорстко зарезервовано для фону (background). Впроваджено алгоритм зсуву індексів `(label - 1) % 10` для коректної трансляції виходів нейромережі у реальні значення цифр на лічильнику.

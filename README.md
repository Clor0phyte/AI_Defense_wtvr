# Розпізнавання показників водяного лічильника (YOLOv8 + Custom CNN)

## Опис проєкту
Веб-додаток на базі Streamlit для автоматичного зчитування показників з фотографій водяних лічильників. Проєкт використовує двохетапний підхід комп'ютерного зору: виявлення екрана лічильника за допомогою YOLOv8 та розпізнавання окремих цифр за допомогою кастомної згорткової нейромережі (CNN) на PyTorch.

## Архітектура
Процес розпізнавання поділено на два незалежні етапи:
1. **Виявлення об'єкта (YOLOv8-OBB):** Модель натренована знаходити 4 кути екрана лічильника (Oriented Bounding Box). Це дозволяє коректно локалізувати циферблат навіть на фотографіях, зроблених під кутом.
2. **Класифікація (Custom CNN):** Згорткова нейромережа, яка отримує на вхід нормалізовані чорно-білі сегменти зображення (32x32 пікселі) і класифікує кожну з 8 нарізаних цифр (від 0 до 9).

## Структура репозиторію
* `app.py` — головний файл веб-додатка, що містить логіку інтерфейсу, препроцесингу та інференсу моделей.
* `models/` — директорія для збережених ваг моделей (`best.pt` для YOLO, `cnn_digits.pt` для CNN).
* `notebooks/` — Jupyter ноутбуки з повним циклом підготовки проєкту (генерація синтетичного датасету, тренування CNN та YOLO).
* `requirements.txt` — список Python-залежностей, необхідних для запуску проєкту.

## Локальний запуск

1. Створіть та активуйте віртуальне середовище:
```bash
python -m venv venv
.\venv\Scripts\Activate.ps1
```

2. Встановіть необхідні залежності:
```bash
pip install -r requirements.txt
```

3. Запустіть веб-додаток через Streamlit:
```bash
streamlit run app.py
```

Після виконання команди додаток буде доступний у браузері за адресою `http://localhost:8501`.

## Технічні особливості реалізації
* **Генерація синтетичного датасету:** Для навчання класифікатора цифр написано автоматизований скрипт, який генерує 10 000 зображень машинного шрифту з накладанням випадкового шуму. Це імітує реальні умови (бруд, подряпини на склі) без необхідності ручної розмітки тисяч фотографій.
* **Адаптивна бінаризація:** Для боротьби з глибокими тінями та нерівномірним освітленням циліндричного лічильника замість глобальних методів (наприклад, методу Оцу) використовується `cv2.adaptiveThreshold`. Алгоритм вираховує локальний поріг контрасту, що дозволяє чітко виділити як чорні, так і червоні цифри.
* **Математичне вирівнювання та автоповорот:** Для компенсації спотворень перспективи застосовується `cv2.warpPerspective`. Пропорції екрана розраховуються через Евклідову відстань між знайденими кутами. Також імплементовано алгоритм автоорієнтації, який автоматично розвертає вертикальні фотографії в горизонтальне положення перед етапом нарізки.
